# Heart Rate Overlay

A high-performance, ad-free Android heart rate overlay application built natively with .NET MAUI. 

Designed specifically for athletes, this app connects to your Bluetooth Low Energy (BLE) heart rate monitor and displays your live BPM directly over your other apps—like your boxing round timer, training videos, or music player. It features a premium, dark-themed "fight-camp" aesthetic designed to minimize eye strain and stay out of your way on the gym floor.

## Features
* **Global Overlay:** Displays your live heart rate on top of any other active Android application.
* **Bluetooth LE Integration:** Scans and connects securely to standard BLE chest straps and optical armbands.
* **Fully Customizable:** Adjust the text size, text color, and screen position dynamically.
* **Sleek Dark Mode:** Built entirely around a custom `FightBlack`, `NeonGreen`, and `NeonBlue` UI palette.
* **Zero Interruptions:** 100% free. No ads, no paywalls, no nonsense.

## Tech Stack
* **Framework:** .NET MAUI (C# / XAML)
* **Toolkit:** .NET MAUI Community Toolkit
* **Architecture:** MVVM (Model-View-ViewModel)
* **State Management:** Native `Preferences` API for persisting user customizations
* **Target Platform:** Android
